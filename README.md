# Training

## 축산기사 필답 암기장 (`livestock/`)

축산기사 필답형 기출 201문항을 외우기 위한 웹 앱입니다. `livestock/index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

- **암기 카드**: 문제를 보고 답안을 써 본 뒤 정답과 비교합니다. 써 둔 답안에서 핵심어를 몇 개 맞혔는지 알려 주고, 모름·애매·완벽으로 스스로 채점합니다.
- **힌트 보고 쓰기**: 힌트를 보면서 답안을 직접 써 봅니다. 서술형은 1단계에서 핵심어 초성과 항목 수, 2단계에서 핵심어 첫 글자만 남긴 정답 틀을 보여 줍니다. 계산 문제는 1단계에서 공식의 용어를 초성으로 가리고(예: 자본 회전율 = (ㅁㅊㅇ/ㅊㅈㅂㅇ) x □) 구할 값의 순서만 보여 주며, 2단계에서 공식이 드러난 풀이식을 숫자만 □로 가려 보여 줍니다. 암기 카드에서도 "힌트 보기"(H 키)로 쓸 수 있습니다.
- **빈칸 채우기**: 정답 속 핵심어(용어, 나열 항목, 계산 결과)가 빈칸으로 나옵니다.
- **순서 맞추기**: 정자 형성 과정, 유즙 배출 순서처럼 단계가 있는 7문항을 순서대로 배열합니다.
- **모의고사**: 10·20·30문항을 서술한 뒤 문항별로 맞음·부분·틀림을 매겨 점수를 냅니다.
- **못 외운 문제**: 학습 중 '모름'으로 표시한 문제는 그 자리에서 다시 나오지 않고 따로 모입니다. 홈의 "못 외운 문제 모아 보기", 학습 범위의 "못 외운 문제", 문제집의 "못 외운" 필터로 모아서 다시 공부합니다.
- **계산기**: 계산 문제에는 문제 옆(휴대폰에서는 아래)에 계산기가 붙습니다. 괄호·거듭제곱(^)·퍼센트를 계산하고, 결과를 답안 칸에 바로 넣을 수 있습니다.
- **문제집**: 분야·계산·별표·못 외운 문제로 걸러 보고 검색합니다.
- 채점 결과에 따라 복습 간격(1·2·4·7·14일)이 정해지며, 학습 기록은 브라우저(localStorage)에 저장됩니다.

문항 데이터는 `livestock/js/data.js`에 있습니다.
