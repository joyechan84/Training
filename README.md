`jlpt-n3/index.html`을 브라우저로 열면 바로 사용할 수 있어요 (설치 불필요, 진도는 브라우저에 저장).

| 구성 | 내용 |
| --- | --- |
| 📅 학습 계획 | Day 1~24 신규 학습 + Day 25~26 총복습, D-Day 카운트다운, 일별 체크리스트·진도율 |
| あ 가나 표 | 히라가나·가타카나 전환, 청음·탁음·요음·외래어 표기, 탭하면 발음, 헷갈리는 글자 정리, 가나 읽기 퀴즈 |
| 漢 한자 240자 | 하루 10자 · 음독/훈독/한국어 훈음/예시 단어 (Day 1~8 N5 → 9~14 N4 → 15~24 N3) |
