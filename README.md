# Training

## 축산기사 필답 암기장 (`livestock/`)

축산기사 필답형 기출 201문항을 외우기 위한 웹 앱입니다. `livestock/index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

- **암기 카드**: 문제를 보고 답안을 써 본 뒤 정답과 비교합니다. 써 둔 답안에서 핵심어를 몇 개 맞혔는지 알려 주고, 모름·애매·완벽으로 스스로 채점합니다.
- **힌트 보고 쓰기**: 힌트를 보면서 답안을 직접 써 봅니다. 서술형은 1단계에서 핵심어 초성과 항목 수, 2단계에서 핵심어 첫 글자만 남긴 정답 틀을 보여 줍니다. 계산 문제는 1단계에서 숫자를 □로 가린 공식 틀, 2단계에서 최종 답만 가린 풀이 과정을 보여 줍니다. 암기 카드에서도 "힌트 보기"(H 키)로 쓸 수 있습니다.
- **빈칸 채우기**: 정답 속 핵심어(용어, 나열 항목, 계산 결과)가 빈칸으로 나옵니다.
- **순서 맞추기**: 정자 형성 과정, 유즙 배출 순서처럼 단계가 있는 7문항을 순서대로 배열합니다.
- **모의고사**: 10·20·30문항을 서술한 뒤 문항별로 맞음·부분·틀림을 매겨 점수를 냅니다.
- **문제집**: 분야·계산·별표·오답으로 걸러 보고 검색합니다.
- 채점 결과에 따라 복습 간격(1·2·4·7·14일)이 정해지며, 학습 기록은 브라우저(localStorage)에 저장됩니다.

문항 데이터는 `livestock/js/data.js`에 있습니다.
